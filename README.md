# 🔎 FindIt — Lost & Found Matcher

A web application that helps people report lost and found items and find possible matches.

## 🚀 Live Website

👉 https://findit-lost-found-3ykc6.vercel.app

## 🛠️ Technologies Used

- React.js
- Vite
- Java Spring Boot
- TiDB Database
- Vercel (Frontend Hosting)
- Render (Backend Hosting)

## ✨ Features

- Report lost and found items
- Browse submitted items
- Connect frontend to backend API
- Store item information in the database
